# Daily Poem Feature

## Overview

A daily poem generated by Google Gemini AI, stored in your Neon PostgreSQL database, and displayed on your homepage.

## Architecture

```
GitHub Actions (cron, daily)
  └─> POST /api/poems/generate
        └─> Gemini API (free tier)
        └─> Save to Neon DB (poems table)

Homepage (user visits)
  └─> GET /api/poems/today
        └─> Read latest from Neon DB
        └─> Render via <Poem /> component
```

## Setup Steps

### 1. Get a Gemini API Key (free)

1. Go to [Google AI Studio](https://aistudio.google.com/app/apikey)
2. Create a new API key
3. Add it to your Vercel project as `GEMINI_API_KEY`
4. Also add it to your local `.env.local` for testing

### 2. Configure GitHub Actions

1. In your GitHub repository settings, add these secrets:
   - `API_URL` — your Vercel deployment URL (e.g., `https://your-portfolio.vercel.app`)

2. The workflow file `.github/workflows/generate-poem.yml` will automatically run daily at midnight UTC.

3. You can also trigger it manually via "Actions" > "Generate Daily Poem" > "Run workflow".

### 3. Verify

- Check your Vercel deployment has `GEMINI_API_KEY` set
- Trigger the GitHub Actions workflow manually
- Check the logs to confirm a poem was generated
- Visit your homepage to see the poem

## API Endpoints

### `POST /api/poems/generate`

Generates a new poem using Gemini 2.0 Flash and saves it to the database.

**Response:** `{ id: number, generatedAt: number }`

### `GET /api/poems/today`

Fetches the most recently generated poem.

**Response:** `{ id: number, content: string, generatedAt: number }`

## Database Schema

```sql
CREATE TABLE "poems" (
  "id" integer PRIMARY KEY GENERATED ALWAYS AS IDENTITY,
  "content" text NOT NULL,
  "generated_at" integer NOT NULL
);
```

## Free Tier Limits

- **Gemini 2.0 Flash**: 1500 requests/day, 60 requests/minute (free, no credit card)
- **GitHub Actions**: 500 build minutes/month (free for public repos)
- **Neon Postgres**: 512MB storage (free tier)

A daily poem uses ~1 request per day, well within all limits.
